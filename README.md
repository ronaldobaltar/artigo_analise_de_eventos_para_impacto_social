Esse repositório contém o conteúdo do artigo "Análise de Eventos para Monitoramento de Impacto Social" de autoria de Ronaldo Baltar e Cláudia Siqueira Baltar.

O objetivo do artigo é demonstrar o uso da Análise de Eventos e Análise Sequencial com o pacote R TraMineR como recurso metodológico para o monitoramento de projetos e políticas de impacto social.
